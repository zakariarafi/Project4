# Prompt Workload

`gsm8k_10.jsonl` akan menyimpan sekitar sepuluh prompt canonical untuk seluruh
benchmark. Setiap baris harus memiliki `id` dan `prompt`.

Sebelum menambahkan konten, catat sumber, lisensi, metode pemilihan, dan apakah
teks sudah diadaptasi. Jangan mengubah isi prompt setelah eksperimen dimulai;
buat versi baru/experiment ID baru bila perlu.
